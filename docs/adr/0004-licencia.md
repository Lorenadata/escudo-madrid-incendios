# ADR-0004 — Licencia EUPL-1.2

**Estado:** aceptada por Lorena Marcos el 07/11/2026; código publicado abierto en GitHub. EUPL-1.2 es la licencia abierta promovida por la Comisión Europea para software del sector público, compatible con GPL/AGPL/LGPL/MPL, y facilita la reutilización por administraciones (criterio de viabilidad y de código abierto). Alternativas: Apache-2.0, AGPL-3.0.
